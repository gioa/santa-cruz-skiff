# Hold-to-lift fishing fight (v72)

First-person hand-held rod control now uses hold/release rather than touch-position steering. A hold requests one bounded lift; release lowers at a controlled rate and requests winding only during recovery/slack take-up. After recovery manual winding remains available. The chosen rod direction stays fixed. Pointer cancellation, loss of capture, focus loss, pause, mounting and fight end cancel the gesture without triggering recovery. Space/Enter provide equivalent keyboard operation. Direct free pose updates are rejected during a hand-held fight.

The controller supplies rod targets and crank requests to the existing line/fish solver; it does not teleport fish or subtract line itself. Fish mass, body drag area, pull and drag threshold affect lift speed and back-drive. Surges may push a held rod down; actual load controls bend/tip response; actual crank and payout drive hands/reel animation, existing audio and supported haptics. Illustrative targets/rates are game tuning, not a claim of measured forces from a real rod. No tension-number HUD was added.

Validation: syntax check and 706 tests, including contact ownership/cancellation, ignored pointer movement, pause/mount/landing, small-versus-large resistance, surge back-drive, line conservation, finite hold, recovery, manual reel handoff and 10/20/60 Hz consistency. Existing hook/escape, fish effort, rod response and drag physics tests still pass.

Browser QA on 390×844 with a labelled, isolated 32 in halibut fixture: hold reached ~66 degrees with crank 0; release moved to 62.4 degrees with actual crank .92 turns/s and retrieval .60 m/s, then stopped winding at 24 degrees. Dragging the canvas preserved azimuth 70; drag adjustment remained usable (65 → 70). No console errors. Images show the production view, with QA hold/release buttons calling the production binding; they are absent in the published game. Final unit validation additionally checks that manual reel operation remains available after recovery. Temporary dist fixture files removed before release.
