# Itemized fishery inspection and whole-catch confiscation

The game now shows a persistent inspection notice with each supported violation, its fish/common name and measured value versus the existing rule (or gear/season/location evidence). A confirmed violation confiscates every currently carried fish, including otherwise legal catches. Released and previously settled catches remain historical records. Fines retain the existing tuning: 100 credits per violating fish in Santa Cruz, 80 credits for entering the closed Pacifica pier. Whole-catch confiscation is a game rule, not a statement of real-world enforcement.

Validation: 758 release tests, including mixed legal/illegal cargo, no violations, water patrol and dock checks, gear/size/season/bag detail, debt recovery from later legitimate catches, legacy/pending saves, no duplicate fines or fish sales, closed-pier confiscation and restored notices. Existing daily catch-history accounting is preserved.

Browser checks at 390 × 844: actual eight-second Santa Cruz shore inspection, acknowledgement, journal reopening, reload/resume with 0 credits / 75 owed and both fish confiscated; Pacifica actual gate/patrol path, reload of pending report, same 25-paid / 55-owed amounts and two confiscated fish. No console errors. Local fixture bootstraps are stored here for reproducibility and removed from dist before release.
