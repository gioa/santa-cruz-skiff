# 船、海流和钓组：现有实现核查

核查日期：2026-09-27。基于发布提交 d8bd2be 的相关物理与投影实现；本地复现脚本调用当前工作区的同一实现。此次为研究与缺陷复现，没有修改游戏物理或发布新版本。

## 正确的相对关系

必须区分三种速度：海水对地速度 U(x,z,depth,time)、船对地速度 Vboat、钓组/鱼线各段对地速度 Vrig。

- 船相对于水的速度是 Vboat − U_surface，决定船体的水阻。风相对于船的速度决定风阻。风吹船造成的额外偏移称为 leeway，不能简单等同于海流。
- 钓组相对于水的速度是 Vrig − U_local，决定铅坠、饵和线段各自的水阻；阻力方向抵抗相对运动，常用近似大小与速度平方、迎流面积和阻力系数有关。
- 钓组相对于船的位移变化率是 Vrig − Vboat，决定线会往哪里斜，但不能只靠这个速度直接推出完整线形和张力。
- 无风、均匀海流、未触底且经过加速过渡后，船和悬空钓组可大致同速随水漂移。此时不应因为对地移动很快就人为产生巨大的横向线阻。重力、放线、惯性和线阻仍存在。
- 风使船比水下钓组漂得更快，或者深浅层流向/流速不同，便会拉开距离。线既可能向船后偏，也可能向船侧甚至前方偏，不由船首朝向固定决定。
- 铅坠触底后应计算海底支撑与摩擦：弱拖力可停住，超过摩擦/接触阈值才滑、滚、跳或被提离底。拖底不等于永久挂底；挂底是另一个约束状态。
- 深水中线本身受流，可能形成弯曲/肚线。更重的坠通常改善下沉与保持位置，但不能消除整条线上的流阻。

## 已确认的问题和对照结果

1. **普通正式海况没有 current 输入。** `marine.js` 仅装载风、浪、温度与潮高；`fishingCurrent(sea)` 返回 x=0,z=0。当前看到的漂移有可能主要是风压/波动，而非实测海流。潮高不是水平流速；不能用涨潮/落潮直接决定某个方向的流。
2. **底坠被强制当作水粒子平移。** `pixel-fishing-physics.js` 非挂底分支每步直接执行 lure.x += current.x*dt，触底时也不例外。复现：约 0.1 kn 弱流、60 秒、静止竿尖、10 m 水深、充足松线；3 oz 与 12 oz 坠都在保持 bottomContact=true 的情况下平移 3 m（9.84 ft），且相同张力。当前代码不存在用于区分停住和拖底的摩擦受力判断。
3. **单一相对流代表整个钓组。** 阻力用 |U − Vboat| 代表全部线和饵，没有钓组独立的水平速度、分段线速度、深度流场。悬空且接近稳态可作为粗略近似；钓组触底、不同水层或船突然加速时不适用。
4. **画面额外放大相对位移。** fishingScenePoint = boat + 3.0315*(rig − boat)。这是之前恢复码头/船比例时引入的钓组专用投影。固定海底点的钓组在船移动 1 m 时，显示坐标会反向移动 2.0315 m；相对于船的画面位移是实际值的约 3.03 倍。这会让漂移观感偏大，甚至看起来像底坠往相反方向滑。应修正钓组/海底坐标关系，保留用户认可的码头和船体比例。
5. **尾波样本仍固定在对地坐标。** 现有新尾波沿船经过的轨迹采样，但没有随表层水流输运。有实测海流后，旧尾波也应被表层流带走；不能永远钉在地图上。

对照中已有正确部分：把同样 0.5 m/s 流速加到船和悬空钓组，10 秒后两者均对地移动 5 m；相对横向偏移约 0，深度与竿负荷与静水对照相同。船体阻力也已经使用船相对水速度。这说明应修正耦合、触底和投影，不能把全部相对流逻辑简单反向或增加一个漂移倍率。

完整数值见 results.json。复现：在项目根目录运行 `node reports/current-audit/reproduce.mjs`。

## 修正顺序与验收

1. 先统一对地、对水与屏幕坐标：保持现有船/码头外观尺寸，固定海底目标在同一地图位置。现有测试应加入固定挂点随船漂移仍不移动的断言。
2. 钓组具有独立速度；重力/浮力、局部相对水阻、鱼线拉力和底部接触共同驱动运动。不能仅做 current*dt 后再强行投回线长球面。
3. 区分悬空、触底静止、拖底、挂底；加入近似静/动摩擦与线张力，明确系数属于游戏标定，不能伪称真实海底测量。
4. 鱼线至少分段采样水流与阻力，分别处理松弛与张紧；底坠被固定时仍有流过线的阻力。
5. 接入 CeNCOOS/IOOS HF Radar 表层流的向量、时间与有效性。没有覆盖或过期时标注缺测/模型估计，不能宣称实测为零；深层流必须使用独立观测/模型，不能把表层流复制到底部当作测量。
6. 验证静水、同流漂移、只有风、固定船、固定底坠、强弱流与不同坠重、垂向剪切、反向海流、暂停恢复和多帧率。采用同一物理时间步，让加速航程在部署钓组期间不产生船/线不同时间倍率。
