## 哪些最值得先深化资料

按“与现有场景的差异＋权威数据可得性”判断，建议下次从以下五类里选；这是研究排序，不是实现排期：

1. **SF Bay中央湾船钓**：1 m湾底数据与多点水动力资料可支撑深槽、岛边、漂流的真实区别。
2. **Tomales Bay**：有湾底网格，狭长潮汐湾能与开放海滩拉开差异。
3. **San Diego Bay**：海草、公共pier、小艇和海上饵站，适合丰富岸／船共存玩法。
4. **Anacapa**：岛礁、海带、风浪遮蔽与跨海航程，视觉与操作差异最大之一。
5. **Tahoe或Crowley**：一个强调深冷清水，一个强调高地开阔水库与虫饵，作为淡水扩展候选。

若更想延续沙滩岸钓，优先深化 **Bodega / Doran**，但必须采集近岸断面和实际沙色，不能复制Pacifica的黑沙和浪槽布局。

## 本轮查出的重要易错点

- **码头、下水点与钓鱼许可是不同事实。** Berkeley旧Pier关闭；Redondo旧Sportfishing Pier不能与其他仍有垂钓用途的pier混称；La Jolla Shores可下水并不意味着旁边保护水域可钓。详见北岸/中南岸档案。
- **运营期与鱼季不同。** Tahoe的El Dorado Beach入口从2026-09-08起因工程关闭；Crowley经营者计划2026-10-25中午结束本季运营，鱼类规则另行判断。[Tahoe城市公告](https://www.cityofslt.gov/296/Boat-Ramp-at-El-Dorado-Beach)、[Crowley经营公告](https://www.crowleylakefishcamp.com/)。
- **当前规则与历史生态分开。** 北岸salmon关闭、Monterey anchovy饵用/食用限制、Delta白鲟放流限制都作为有时间的记录。游戏未来年份需复核，不能永久抄成物种属性。
- **鱼类样带与其他生物调查不能混用。** 质量审查已将Channel Islands数据入口改为鱼类Fish Transect历史调查，不拿无脊椎动物尺寸频率表来生成鱼群。
- **沙色、trough和鱼群概率没有随意填数。** 未取得实际测量或足够照片的地方明确标为unknown/待补。保护区生态丰富也不代表可钓或开放区具有同样丰度。
